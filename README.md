# Ground Shot Cricket

A small browser cricket game inspired by arcade cricket pages. The game emphasizes bat-and-ball connection, pitch bounce timing, and grounded cricket shots.

## Play

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- Press `Space` when the ball reaches the batter.
- Timing the shot after the pitch bounce creates the best connection.
- Perfect timing can launch a lofted six; good timing creates a skidding ground drive; early or late timing creates chips, edges, misses, or wickets.
